# État-Major Personnel

Base complète React + Vite + Cloudflare Workers + D1 + PWA.

## Ce que contient cette base

- login avec code préalable obligatoire
- bootstrap initial d’un workspace
- session sécurisée par cookie
- CRUD pour missions, projets, campagnes, objectifs, tâches, ressources, décisions, scénarios
- historique horodaté
- dashboard synthétique
- moteur de score stratégique
- zone IA structurée
- manifest PWA + service worker
- déploiement prêt pour Cloudflare Workers
